API e infraestructura tributaria

La API opera con el negocio, certificado y secuencia oficial configurados aquí.

API habilitada

Headers de cliente

X-API-Key: <api_key>
X-API-Secret: <secret_key>
Content-Type: application/json

La Secret Key se muestra únicamente al crearla. Nunca se guarda ni se registra en el navegador.

Endpoints disponibles para integradores

  • GET /api/v1/facturada/license
  • POST /api/v1/facturada/invoices
  • POST /api/v1/facturada/invoices/emit
  • GET /api/v1/facturada/invoices
  • POST /api/v1/facturada/credit-notes
  • GET /api/v1/facturada/openapi.json

RUC, establecimiento, punto de emisión y ambiente deben coincidir con esta configuración.

Clientes API y logs quedan preparados en estas rutas. Se habilitarán cuando el backend publique endpoints administrativos específicos; no se usa /api/resource como sustituto.
