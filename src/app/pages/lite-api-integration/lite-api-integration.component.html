Cómo conectarte

  1. 1

    Usa la URL base de esta pantalla en tu sistema.

  2. 2

    Autentica cada solicitud con la API Key y la Secret Key del API Client. Guarda la Secret Key en un lugar seguro: no se puede volver a mostrar.

  3. 3

    Emite en el mismo ambiente del API Client. Un client de Pruebas no puede emitir en Producción.

  4. 4

    Ante un estado pendiente, consulta el comprobante; no lo vuelvas a emitir.
